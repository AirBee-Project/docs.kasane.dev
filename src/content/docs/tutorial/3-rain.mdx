時間とともに変わる雨のデータを書き込みます。テーブルを「時間を扱う」設定で作り、空間ID に時間を付けた[時空間ID](/concepts/spatial-id/#時空間id) で書き込みます。時間間隔は 3600 秒（1 時間）で、2025-01-01 の 0 時台と 1 時台（UTC）を使います。

<LangStep step="map/3-rain" />

0 時台は、町全体の小雨（10）のうち東側を 30 で上書きしています（書き込みは上書き）。
