## Step 4：Upsert と Remove

`a`（値 `7`）と、その東隣の空いているボクセル `b` をまとめて Upsert し、そのあと `a` だけを Remove します。

<Code code={s4} lang="ts" title="04-upsert-remove.ts" />

<TutorialRunner step="04-upsert-remove" />

実行結果の例：

```text
Upsert 後: [ '20/0/931389/412900 => 7', '20/0/931390/412900 => 100' ]
OK  a は元の値 7 のまま
OK  b には 100 が入る
Remove 後: [ '20/0/931390/412900 => 100' ]
OK  a が消え、b だけが残る
```

3 つの書き込み操作の違いをまとめると次のようになります。

- Insert：空いていれば書く、値があれば上書きする
- Upsert：空いている部分にだけ書く（既存の値はそのまま）
- Remove：指定した部分を消す
