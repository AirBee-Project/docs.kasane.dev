ビルそのものだけでなく、ビルに近い場所も危険です。ビルから離れるほど危険度が下がるように、まわりに広げます。

こうした計算には**クエリ**を使います。クエリは、テーブルに対する計算を組み立てて、サーバー側で実行する機能です。

- `query.source(データベース名, テーブル名)` で、計算のもとになるテーブルを選びます。
- `falloffX(ズームレベル, 半径, …)` は、値を東西（X）方向に広げながら、半径のボクセル数で 0 になるように減らします。`falloffY` は南北（Y）方向です。
- `client.query(クエリ, 空間ID)` で実行し、指定した場所の結果を受け取ります。

実行結果の例：

```text
ビルA から 0 ボクセル: [ 100n ]
ビルA から 1 ボクセル: [ 75n ]
ビルA から 2 ボクセル: [ 50n ]
ビルA から 3 ボクセル: [ 25n ]
ビルA から 4 ボクセル: [ 12n ]
```

ビルの中は `100`、そこから 1 ボクセル離れるごとに `75`、`50`、`25` と下がります。4 ボクセル離れた場所はビルA の影響が `0` になりますが、近くにあるビルB の危険度が届いているので `12` になっています。

クエリは計算した結果を返すだけで、`buildings` テーブルの中身は変わりません。建物のデータはそのままに、見たいときに何度でも計算し直せます。
