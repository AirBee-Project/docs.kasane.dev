ドローンは風や測位の誤差で予定の位置からずれるので、建物のまわりにバッファが必要です。建物から離れるほどリスクが下がるように、クエリで建物のリスクを周囲に広げます（[クエリの考え方](/concepts/query/)）。

<Steps>

1. **建物のテーブルからクエリを作る**

   クエリは、もとにするテーブルを指定して作り、そこに計算を足していきます。まずは何も計算せずに実行してみます。

   <LangStep step="map/2-falloff/1-source" madori={{ camera: { zoom: 15 }, opacity: 0.6 }} />

2. **東西に広げる**

   falloff を東西（X）方向にかけ、半径 8 ボクセルで 0 になるよう線形に減らしながら広げます。

   <LangStep step="map/2-falloff/2-falloff-x" madori={{ camera: { zoom: 14.5 }, opacity: 0.6 }} />

   建物から 1 ボクセル離れるごとに 12.5 ずつ下がります（小数は切り捨て）。建物から東西へ、赤から青へ色が変わります。

3. **南北にも広げる**

   続けて南北（Y）方向にも falloff をかけます。

   <LangStep step="map/2-falloff/3-falloff-y" madori={{ camera: { zoom: 14.25 }, opacity: 0.6 }} />

   建物のまわりが、四方に広がったリスクで囲まれます。
</Steps>

クエリは計算した結果を返すだけで、`buildings` テーブルの中身は変わりません。
