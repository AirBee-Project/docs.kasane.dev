## チュートリアルの目的

あとで使っていただく負荷試験ツールは、書き込み・検索・クエリを大量に行い、速さと結果の正しさを測ります。チュートリアルでは、同じ操作を小さい範囲で行い、結果を読むのに必要な Kasane の仕様を確かめます。

チュートリアルは、このドキュメントのページ上で実行できます。インストールやアカウントの設定は要りません。

各ステップのコードの下にある「実行する」ボタンを押すと、ブラウザから Kasane に実際にリクエストが送られ、結果がその場に表示されます。コードは Kasane の TypeScript クライアント（`@airbee-project/kasane-client`）を使って、Kasane の API を呼び出しています。期待どおりなら `OK`、違えば `NG` と表示されます。`NG` が出たら Kasane の不具合かもしれないので、表示された内容をそのまま [Issue](/tutorial/next/) で送ってください。


## 進め方

- Step 1 から順に実行してください。Step 3・4 は、Step 2 で作ったテーブルを使います。
- チュートリアルは、みんなで使う体験用のアカウントとデータベースで動きます。書き込んだデータは、ほかの人にも見える可能性があり、定期的に消されます。個人情報や公開できないデータは書き込まないでください。
- 同時に試している人とぶつからないよう、テーブル名には自動で固有の文字が付きます（コードの `t("hello")` の部分）。ページを開き直すと別の名前になるので、そのときは Step 2 からやり直してください。

## コードで使っている道具

各ステップのコードは、次の道具を受け取って動きます。Kasane の操作そのもの（`db.createTable`、`table.insert`、`table.search`、`client.query` など）は、クライアントのメソッドをそのまま使っています（[クライアント API](/docs/api/)）。

| 名前 | 内容 |
| --- | --- |
| `client` | ログイン済みのクライアント |
| `db` / `DB` | 体験用のデータベースと、その名前 |
| `t("名前")` | テーブル名に固有の文字を付ける |
| `check(説明, 条件)` | 条件が正しければ `OK`、違えば `NG` を表示する |
| `log(...)` | 結果欄に表示する（`console.log` の代わり） |
| `resetTable(名前)` | 同じ名前のテーブルが残っていれば消す |
| `WHOLE` | 地球全体・全時間を表す範囲（テーブルの中身をすべて検索するときに使う） |

## 自分の PC で動かしたいとき

同じクライアントを、自分のプロジェクトに入れて使うこともできます。

```sh
npm install https://github.com/AirBee-Project/Kasane-Client-ts/releases/download/v0.0.3/airbee-project-kasane-client-0.0.3.tgz
```

- クライアントは npm には公開しておらず、GitHub Releases の URL を指定してインストールします。
- TypeScript で型チェックをするときは、`tsconfig.json` の `moduleResolution` を `"Bundler"` にしてください。v0.0.3 の型定義は `"NodeNext"` だと読み込めません。
