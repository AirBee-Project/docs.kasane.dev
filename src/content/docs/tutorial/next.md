チュートリアルお疲れさまでした。これで Kasane の基本的な操作は一通り使えるようになっています。

## 次にやること

1. **負荷試験ツールで基本の検証を流す**（準備中）
   コマンド 1 つで、書き込み・検索・クエリの速さと、結果の正しさ（整合性）をまとめて測ります。数分で終わり、結果は自動で運営に送られます。
2. **自分のデータでベンチマークを取る**（準備中）
   ここがいちばんお願いしたいことです。自分の仕事や研究のデータ（時空間ID と値のファイル）を負荷試験ツールに読み込ませると、書き込み・検索・クエリの速さと、読み戻した結果が元のデータと一致するかをまとめて測れます。地図データを時空間ID に変換する方法は [自分のデータを使う](/explore/) を見てください。
3. **気づいたことを送る**（下記）

## 気づいたことを送る

次のようなことがあれば、[Issue](https://github.com/AirBee-Project/docs.kasane.dev/issues/new) で教えてください。

- `NG` が出た（出力をそのまま貼ってください）
- 説明と違う動きをした、エラーの意味が分からなかった
- 使いにくい、分かりにくいと感じた API や手順があった
- このドキュメントで分かりにくいところがあった
- こういう機能が欲しい

Issue は公開されます。パスワードなどのアカウント情報や、公開できないデータは書かないでください。
