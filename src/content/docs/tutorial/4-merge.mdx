Step 2 の建物のリスクと Step 3 の雨の強さを重ね合わせ、町全体のリスクマップを Madori で見ます。

<Steps>

1. **重ね合わせる**

   クエリの merge で、建物のリスクと雨を重ね合わせます。policy は max で、同じ場所では大きい方をその場所のリスクにします。建物のリスクが無い場所は 0 として扱うので、雨の強さがそのままリスクになります。

   <LangStep step="map/4-merge/1-merge" run={false} />

2. **JSON で出力する**

   重ね合わせたクエリで、町全体を 0 時台から 1 時台まで検索します。結果を、Madori が読み込める JSON に変換して出力します。

   JSON では、リスクの値を `value` に重複なく並べ、各時空間ID の `ref` でそのどれかを指します。

   <LangStep step="map/4-merge/2-json" madori={{ camera: { zoom: 14 }, opacity: 0.6 }} />

3. **Madori で見る**

   手順 2 の「実行する」を押すと、右の Madori に JSON が表示されます。次の地図は、実行結果の例を読み込んだものです。

   <MadoriFrame json={mapJson} opacity={0.6} speed={3600} camera={{ bearing: 0, pitch: 55, zoom: 14.5 }} />

   左上の <TablerIcon name="file-description" /> JSON を押すと、読み込んだ `risk` の行が出ます。⬜︎ を押すと透明度のバーが出るので、地図が見やすい濃さに調整します。

   Madori は、値の最大を赤、最小を青としたヒートマップで表示します。0 時台は、建物のまわりが赤く、建物から離れた場所は青く表示されます。タイムバーを 1 時台に進めると、町全体に強い雨が降るので、建物から離れた場所も赤に近い色になります。建物のすぐまわりは、雨より建物のリスクの方が大きいので、色が変わりません。

</Steps>
