Step 2 の建物の危険度と Step 3 の雨の強さを重ね合わせ、町全体の危険度マップを Senri で見ます。

<Steps>

1. **重ね合わせる**

   クエリの merge で、建物の危険度と雨を重ね合わせます。policy は max で、同じ場所では大きい方をその場所の危険度にします。建物の危険度が無い場所は 0 として扱うので、雨の強さがそのまま危険度になります。

   <LangStep step="map/4-merge/1-merge" run={false} />

2. **JSON で出力する**

   重ね合わせたクエリで、町全体を 0 時台から 1 時台まで検索します。結果を、Senri が読み込める JSON に変換して出力します。

   JSON では、危険度の値を `value` に重複なく並べ、各時空間ID の `ref` でそのどれかを指します。

   <LangStep step="map/4-merge/2-json" />

3. **Senri で見る**

   出力した JSON を `.json` ファイルとして保存し、[Senri](https://map.airbee.jp/?debug) で読み込みます。Senri は JSON をファイルからしか読み込めないので、別のタブで開いてください。実行できないときは、<a href={`data:application/json;charset=utf-8,${encodeURIComponent(mapJson)}`} download="danger-map.json">実行結果の例</a>をダウンロードして使えます。

   1. 左上の <TablerIcon name="file-description" /> JSON → <TablerIcon name="plus" /> JSONを追加 で、保存したファイルを選びます。
   2. 追加された `risk` の行の <TablerIcon name="target" /> を押すと、データのある場所と時刻へ移動します。
   3. ⬜︎ を押すと透明度のバーが出るので、地図が見やすい濃さに調整します。

   Senri は、値の最大を赤、最小を青としたヒートマップで表示します。0 時台は、建物のまわりが赤く、建物から離れた場所は青く表示されます。タイムバーを 1 時台に進めると、町全体に強い雨が降るので、建物から離れた場所も赤に近い色になります。建物のすぐまわりは、雨より建物の危険度の方が大きいので、色が変わりません。

</Steps>
