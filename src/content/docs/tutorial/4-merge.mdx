Step 2 の建物の危険度と Step 3 の雨を merge で重ね合わせます。policy は sum、雨が無い場所は既定値 0 として計算します。

<LangStep step="map/4-merge" />

どちらの点もビルA から 2 ボクセルなので、建物の危険度は 50 です。

| | 0 時台 | 1 時台 |
| --- | --- | --- |
| 西 | 50 + 10 = 60 | 50 + 60 = 110 |
| 東 | 50 + 30 = 80 | 50 + 60 = 110 |
