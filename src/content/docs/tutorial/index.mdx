このチュートリアルでは、ドローンが町を飛ぶときの「危険度マップ」を Kasane で作ります。[クイックスタート](/clients/typescript/quickstart/)を終えていれば、上から順に進めるだけで完成します。

:::note[読む前に]
空間ID（`20/0/931389/412900` のような ID）と、範囲を表す `RangeId` を使います。初めての人は、先に[時空間ID の基礎](/concepts/spatial-id/)と[空間ID を作る](/clients/typescript/guide/spatial-ids/)を読んでおくと分かりやすくなります。
:::

## 作るもの

ドローンにとって危ない場所は、2 つの理由で決まるとします。

- **建物の近く**：ぶつかる危険があります。建物は動かないので、一度書き込めば変わらない**静的なデータ**です。
- **雨**：強いほど危険です。時間とともに変わる**動的なデータ**です。

この 2 つを足し合わせて、「今、危ない場所」を時間ごとに求め、地図に表示します。

```text
建物の危険度（静的）  ＋  雨の強さ（時間ごとに変わる）  ＝  時間ごとの危険度
     ビルのまわりほど高い        0 時台：町全体に小雨、東側は雨
                                 1 時台：町全体に強い雨
```

## 進め方

| Step | やること | 使う機能 |
| --- | --- | --- |
| 1 | 建物を書き込む | テーブル、RangeId、`insert` |
| 2 | 建物のまわりに危険度を広げる | クエリ（falloff） |
| 3 | 雨を書き込む | 時間を扱うテーブル、時空間ID |
| 4 | 危険度を足し合わせる | クエリ（merge） |
| 5 | 危ない場所を地図で見る | クエリ（filter）、Senri |

各 Step は、前の Step で作ったテーブルを使います。Step 1 から順に「実行する」を押してください。

舞台は東京駅の丸の内側、東西約 900 m × 南北約 700 m の範囲です。ボクセルはズームレベル 20（1 辺約 30 m）を使います。

## コードの `client` と `db`

各 Step のコードは `export default async function ({ client, db })` の形で、`client` と `db` を受け取っています。

- `client`：ログイン済みの `KasaneClient` です。
- `db`：データベース `tutorial` のハンドル（`client.database("tutorial")`）です。

「実行する」を押すと、このサイトが体験用のユーザーでログインして、この 2 つを渡します。自分のプロジェクトで書くときは、関数の引数の代わりに、先頭で次のように用意すれば同じように動きます（[接続と認証](/clients/typescript/guide/connect/)）。

```ts
import { KasaneClient } from "@airbee-project/kasane-client";

const client = await KasaneClient.connect("https://サーバーのURL", "ユーザー名", "パスワード");
const db = client.database("データベース名");
```
