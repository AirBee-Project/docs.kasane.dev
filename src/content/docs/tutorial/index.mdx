## 重ね合わせるデータ

リスクマップは、次の 2 つのデータを重ね合わせて作ります。

- **建物**：建物そのものと、そのまわりの衝突リスク。静的なデータ
- **天気**：雨が強いほど高リスク。時間とともに変わる動的なデータ

## 自分の環境で動かす

各 Step のコードは、ログイン済みのクライアント（`client`）とデータベース `tutorial`（`db`）を受け取る形で書いています。

<LangTab lang="typescript">

```ts
import { KasaneClient } from "@airbee-project/kasane-client";

const client = await KasaneClient.connect("https://サーバーのURL", "ユーザー名", "パスワード");
const db = client.database("データベース名");
```
