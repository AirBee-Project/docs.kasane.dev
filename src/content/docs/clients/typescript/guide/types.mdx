## 値の型

| 型 | 書く値 | 読んだ値 |
| --- | --- | --- |
| `"text"` | `string` | `string` |
| `"int"` | `number` または `bigint` | `number` |
| `"boolean"` | `boolean` | `boolean` |
| `"enum"` | 選択肢の `string` | `string` |
| `"presence"` | `null` | `null` |

INT に小数を渡すと、クライアントで切り捨てられます（`3.9` → `3`）。読んだ値は `number` なので、`Number.MAX_SAFE_INTEGER`（2<sup>53</sup> − 1）を超える値は精度が落ちます。

## 制約

`createTable` の `constraints` で書き込める値を制限します。制約違反や型の不一致は `[invalid_argument]` になります。

| 型 | 書き方 |
| --- | --- |
| INT | `{ kind: { case: "int", value: { min: 0n, max: 100n } } }` |
| TEXT | `{ kind: { case: "text", value: { minLength: 1n, maxLength: 20n } } }` |
| ENUM | `{ kind: { case: "enumConstraint", value: { choices: ["晴れ", "曇り", "雨"] } } }` |

数値は `bigint` で書きます。

## 型パラメーター

`db.table<T>(名前)` の `T` が、書く値と読んだ値の型になります。サーバーのテーブル定義とは連動しないので、正しい型を自分で指定します。省略時は `string | number | bigint | boolean | null | undefined` です。

INT のテーブルには `<number>` を指定します。

```ts
const risk = db.table<number>("risk");
await risk.insert(80, id);
const value = (await risk.search(id).toArray())[0]?.value; // number | undefined
if (value !== undefined) console.log(value + 1);            // 81
```
