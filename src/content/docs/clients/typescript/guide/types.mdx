## 値の型

| 型 | 書く値 | 読んだ値 |
| --- | --- | --- |
| `"text"` | `string` | `string` |
| `"int"` | `number` または `bigint` | `bigint` |
| `"boolean"` | `boolean` | `boolean` |
| `"enum"` | 選択肢の `string` | `string` |
| `"presence"` | `null` | `null` |

INT に小数を渡すと、クライアントで切り捨てられます（`3.9` → `3`）。

## 制約

`createTable` の `constraints` で書き込める値を制限します。制約違反や型の不一致は `[invalid_argument]` になります。

| 型 | 書き方 |
| --- | --- |
| INT | `{ kind: { case: "int", value: { min: 0n, max: 100n } } }` |
| TEXT | `{ kind: { case: "text", value: { minLength: 1n, maxLength: 20n } } }` |
| ENUM | `{ kind: { case: "enumConstraint", value: { choices: ["晴れ", "曇り", "雨"] } } }` |

数値は `bigint` で書きます。制約の型はサーバー API の型そのままなので、`as never` が必要です。

## 型パラメーター

`db.table<T>(名前)` の `T` が、書く値と読んだ値の型になります。サーバーのテーブル定義とは連動しないので、正しい型を自分で指定します。省略時は `string | number | bigint | boolean | null | undefined` です。

INT のテーブルには `<bigint>` を指定し、書くときも bigint にします。

```ts
const risk = db.table<bigint>("risk");
await risk.insert(80n, id);
const value = (await risk.search(id).toArray())[0]?.value; // bigint | undefined
if (value !== undefined) console.log(value + 1n);           // 81n
```

`<number>` にすると型の上では `value + 1` が通りますが、実際の値は bigint なので実行時に `Cannot mix BigInt and other types` になります。
