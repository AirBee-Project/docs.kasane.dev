Kasane の空間ID の種類は[Kasane での空間ID](/concepts/kasane-spatial-id/)にあります。クライアントでは、種類ごとにクラスがあります。

| 種類 | 作り方 |
| --- | --- |
| `SingleId` | `SingleId.create(z, f, x, y)` |
| `RangeId` | `RangeId.create(z, f, x, y)`。各軸に `[最小, 最大]` か 1 つの値を渡す |
| `FlexId` | `FlexId.create(fのズーム, f, xのズーム, x, yのズーム, y)` |

書き込み・検索・クエリには、どの種類の空間ID も、その配列も渡せます。

実行結果の例：

```text
SingleId: 20/0/931389/412900
parse: 20/0/931389/412900
RangeId: 20/0/931389:931390/412900:412901
中のボクセル: [ '20/0/931389/412900', '20/0/931389/412901', '20/0/931390/412900', '20/0/931390/412901' ]
FlexId: 20/0|20/931389|19/206450
時間つき: 20/0/931389/412900_3600/482136  全時間か: false
```

## 文字列との変換

`toString()` で文字列に、`SingleId.parse()`・`RangeId.parse()`・`FlexId.parse()` で文字列から変換します。書式の誤りや範囲外の値は `SpatialIdError` になります（[エラー処理](/clients/typescript/guide/errors/)）。

## 時間を付ける

`SingleId` と `RangeId` は `withTime(時間間隔, 時間インデックス)` で時空間ID になります。時間間隔には秒数か `Interval.SECOND`・`MINUTE`・`HOUR`・`DAY` を渡します。`RangeId` は時間インデックスに `[最小, 最大]` も渡せます。

`FlexId.withTime` は時間間隔の代わりに時間方向のズームレベルを取ります。通常は `SingleId` か `RangeId` を使ってください（[時空間ID を使う](/clients/typescript/guide/temporal/)）。

## その他のメソッド

| メソッド | 内容 |
| --- | --- |
| `singleId.toRangeId()` | `RangeId` に変換する |
| `rangeId.toSingleIds()` | 中のボクセルを `SingleId` で列挙する |
| `id.isWholeTime()` | 全時間の ID か |
| `SingleId.createUnchecked(...)` | 範囲検証を省いて作る。不正な値での動作は未定義 |

関連する API：[SingleId](/clients/typescript/api/classes/singleid/)、[RangeId](/clients/typescript/api/classes/rangeid/)、[FlexId](/clients/typescript/api/classes/flexid/)、[Interval](/clients/typescript/api/classes/interval/)
