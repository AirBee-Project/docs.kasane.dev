空間ID そのものの意味は、背景知識の[時空間ID の基礎](/concepts/spatial-id/)で説明しています。

## 3 つのクラス

| クラス | 表すもの | 作り方 |
| --- | --- | --- |
| `SingleId` | 1 ボクセル | `SingleId.create(z, f, x, y)` |
| `RangeId` | 直方体に並んだボクセル | `RangeId.create(z, f, x, y)`。各軸に `[最小, 最大]` か 1 つの値を渡す |
| `FlexId` | 軸ごとにズームレベルが違うボクセル | `FlexId.create(fのズーム, f, xのズーム, x, yのズーム, y)` |

書き込み・検索・クエリには、どのクラスの ID を渡してもかまいません。ID の配列も渡せます。ふだんは `SingleId` と `RangeId` を使い、`FlexId` は検索結果の形として出てくることがあります。

実行結果の例：

```text
SingleId: 20/0/931389/412900
parse: 20/0/931389/412900
RangeId: 20/0/931389:931390/412900:412901
中のボクセル: [ '20/0/931389/412900', '20/0/931389/412901', '20/0/931390/412900', '20/0/931390/412901' ]
FlexId: 20/0|20/931389|19/206450
時間つき: 20/0/931389/412900_3600/482136  全時間か: false
```

## 文字列との変換

- `id.toString()` で `"20/0/931389/412900"` の形の文字列になります。テンプレート文字列（`` `${id}` ``）でも同じです。
- `SingleId.parse(文字列)`、`RangeId.parse(文字列)`、`FlexId.parse(文字列)` で文字列から作れます。
- 書式が間違っていたり、値が範囲外だったりすると、`SpatialIdError` が投げられます（[エラー処理](/clients/typescript/guide/errors/)）。

## 時間を付ける

`SingleId` と `RangeId` は、`id.withTime(時間間隔, 時間インデックス)` で時間つきの ID（時空間ID）になります。時間間隔は秒数か、`Interval.SECOND`・`Interval.MINUTE`・`Interval.HOUR`・`Interval.DAY` を渡します。`RangeId` なら、時間インデックスにも `[最小, 最大]` を渡せます。

`FlexId` の `withTime` は引数が違い、時間間隔の代わりに時間方向のズームレベルを取ります。ふだんは `SingleId` か `RangeId` に時間を付けてください。詳しくは [時空間ID を使う](/clients/typescript/guide/temporal/) で説明しています。

## そのほかの便利なメソッド

| メソッド | 内容 |
| --- | --- |
| `singleId.toRangeId()` | `RangeId` に変換する |
| `rangeId.toSingleIds()` | 中のボクセルを 1 つずつ `SingleId` で取り出す |
| `id.isWholeTime()` | 時間を持たない（全時間の）ID か |
| `SingleId.createUnchecked(...)` | 範囲の検証をせずに作る。速いが、不正な値を渡したときの動きは決まっていない |

## まとめ

- 1 ボクセルは `SingleId`、直方体は `RangeId` で作る
- `toString()` と `parse()` で文字列と変換できる
- `withTime()` で時間を付ける
