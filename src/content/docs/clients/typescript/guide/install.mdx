`@airbee-project/kasane-client` は、Kasane を TypeScript から使うためのクライアントライブラリです。Kasane のサーバーとのやり取りはすべてこのライブラリが引き受けるので、アプリからは関数を呼ぶだけで、テーブルの作成・書き込み・検索・クエリができます。

## インストール

<InstallTabs pkg="https://github.com/AirBee-Project/Kasane-Client-ts/releases/download/v0.0.3/airbee-project-kasane-client-0.0.3.tgz" />

使うものを名前で読み込みます。

```ts
import { KasaneClient } from "@airbee-project/kasane-client";

const client = await KasaneClient.connect("https://kasane.example.com", "alice", "alice-pass");
console.log(await client.listDatabases());
```

## 動く環境

| 環境 | 対応 |
| --- | --- |
| Node.js | 対応（標準の `fetch` を使うので、18 以上。22 で動作を確認） |
| Bun | 対応 |
| ブラウザ | 対応（このサイトの「実行する」ボタンも、ブラウザでクライアントを動かしています） |

クライアントは **gRPC-Web** で Kasane と通信します。同じコードが Node.js でもブラウザでも動きます。

ブラウザから Kasane に直接つなぐときは、Kasane のサーバー側で、そのサイトからのアクセス（CORS）が許可されている必要があります。また、ブラウザで動くコードに書いたパスワードは誰でも見られるので、読み取り専用のユーザーを使うなど、見られても困らないユーザーにしてください。

## TypeScript の設定

型定義はパッケージに含まれています。`tsconfig.json` の `moduleResolution` は `"Bundler"` にしてください。v0.0.3 の型定義は、`"NodeNext"` だと読み込めません。

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "target": "ES2022",
    "strict": true
  }
}
```

値の型の注意点は[値の型と制約](/clients/typescript/guide/types/#typescript-での値の型)で説明しています。
