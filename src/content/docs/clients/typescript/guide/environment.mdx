## TypeScript の設定

`moduleResolution` は `"Bundler"` にしてください。型定義は `"NodeNext"` では読み込めません。

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "target": "ES2022",
    "strict": true
  }
}
```
