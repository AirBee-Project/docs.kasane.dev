```ts
import { KasaneClient } from "@airbee-project/kasane-client";

const client = await KasaneClient.connect("https://kasane.example.com", "alice", "alice-pass");
console.log(await client.listDatabases());
```

## 動作環境

| 環境 | 対応 |
| --- | --- |
| Node.js | 18 以上（標準の `fetch` を使用。22 で確認） |
| Bun | 対応 |
| ブラウザ | 対応 |

ブラウザから直接接続するには、Kasane サーバー側でそのオリジンからの CORS を許可する必要があります。

## TypeScript の設定

`moduleResolution` は `"Bundler"` にしてください。型定義は `"NodeNext"` では読み込めません。

```json
{
  "compilerOptions": {
    "module": "ESNext",
    "moduleResolution": "Bundler",
    "target": "ES2022",
    "strict": true
  }
}
```
