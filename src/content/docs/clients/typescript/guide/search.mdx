`table.search(ID, オプション)` は、指定した範囲と重なる部分だけを返します。

| オプション | 内容 |
| --- | --- |
| `format` | 結果の ID の形式。`"singleId"`・`"rangeId"`（既定）・`"flexId"` |
| `policy` | テーブルより細かい ID の扱い（[書き込む](/clients/typescript/guide/write/#テーブルより細かい-id)） |

戻り値は `ResultStream` で、要素は `{ id, value }`（`ResultItem`）です。

## 結果の受け取り方

| 書き方 | 用途 |
| --- | --- |
| `for await (const { id, value } of results)` | 1 件ずつ処理する |
| `await results.toArray()` | 配列にする |
| `await results.toDictionaryMap()` | 値ごとに ID をまとめる（`Map<値, 空間ID[]>`） |

`ResultStream` は 1 回しか読めず、2 回目は空になります。

```text
toDictionaryMap: 1 => [ '20/0/931389/412900', '20/0/931390/412900', '20/0/931391/412900' ]
1 回目: 3 件
2 回目: 0 件
```

## 結果の ID の形式

<StepCode code={c0} title="formats.ts" />

<TutorialRunner step="guide/formats" />

実行結果の例：

```text
singleId [ '20/0/931389/412900', '20/0/931389/412901', '20/0/931390/412900', '20/0/931390/412901' ]
rangeId [ '20/0/931389/412900:412901', '20/0/931390/412900:412901' ]
flexId [ '20/0|20/931389|19/206450', '20/0|20/931390|19/206450' ]
```

- `singleId`：1 ボクセルずつ。広い範囲では件数が非常に多くなる
- `rangeId`：まとめられる部分をまとめる
- `flexId`：内部の保存形式のまま
