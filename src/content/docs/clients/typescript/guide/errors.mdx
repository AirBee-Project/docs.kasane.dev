## サーバーのエラー

`e.message` の先頭の `[ ]` が種類です。

| 種類 | 主な原因 | 判定する関数 |
| --- | --- | --- |
| `invalid_argument` | 型の不一致、制約違反、ズームレベルの上限超え、使えない時間間隔、`policy` の指定漏れ | — |
| `not_found` | テーブルが無い | `isNotFoundError(e)` |
| `already_exists` | 同名のテーブルがある | `isAlreadyExistsError(e)` |
| `permission_denied` | 権限が無い | `isPermissionDeniedError(e)` |
| `unauthenticated` | ログインできていない | `isUnauthenticatedError(e)` |
| `unknown` | サーバーに接続できない（`fetch failed`、`Unable to connect`） | — |
| `internal` | サーバー内部のエラー（Kasane の不具合の可能性） | — |

## SpatialIdError

`e.info.kind` が原因です。

| kind | 内容 |
| --- | --- |
| `ZOutOfRange` | ズームレベルが範囲外 |
| `FOutOfRange` / `XOutOfRange` / `YOutOfRange` | インデックスが範囲外 |
| `TOutOfRange` / `TIntervalError` | 時間インデックスや時間間隔が不正 |
| `ParseSpatialIdFormat` | `parse` の文字列の書式が不正 |

関連する API：[isKasaneError](/clients/typescript/api/functions/iskasaneerror/)、[SpatialIdError](/clients/typescript/api/classes/spatialiderror/)
