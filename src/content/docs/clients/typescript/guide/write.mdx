| メソッド | 動作 |
| --- | --- |
| `table.insert(値, ID)` | 書き込む。既存の値は上書きする |
| `table.upsert(値, ID)` | 空いている部分にだけ書き込む |
| `table.remove(ID)` | 指定した部分を消す |

空間ID には、[どの種類](/concepts/kasane-spatial-id/)（`SingleId`・`RangeId`・`FlexId`）も、その配列も渡せます。

<StepCode code={c0} title="write-modes.ts" />

<TutorialRunner step="guide/write-modes" />

実行結果の例：

```text
Insert 後: [ '20/0/931389/412900 => 7' ]
Upsert 後: [ '20/0/931389/412900 => 7', '20/0/931390/412900 => 100' ]
Remove 後: [ '20/0/931390/412900 => 100' ]
```

:::caution
JSDoc には「`insert` は既存データと重複がある場合はエラー」とありますが、実際の動作は上書きです。
:::

## まとめて書き込む

1 回の呼び出しで書ける値は 1 つです。同じ値のボクセルは空間ID の配列にするか、隣り合う部分を `RangeId` にまとめて 1 回で送ります。

<StepCode code={c1} title="bulk-write.ts" />

<TutorialRunner step="guide/bulk-write" />

実行結果の例：

```text
値 2: 100 ボクセル
値 1: 100 ボクセル
count: 10n
```

`info()` の `count` は [FlexId](/concepts/kasane-spatial-id/#flexid) の数なので、200 ボクセルが 10 になります。

## テーブルより細かい ID

最大ズームレベルより細かい ID の扱いは、3 つ目の引数（`ZoomLevelPolicy`）で選びます。`search` と `remove` も同じです。

| 指定 | 動作 |
| --- | --- |
| `"error"`（既定） | エラーにする |
| `"ignore"` | その ID を無視する |
| `"normalize"` | 最大ズームレベルの親に丸める（元より広い範囲に書き込まれる） |
