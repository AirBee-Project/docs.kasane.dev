## 接続する

`KasaneClient.connect(URL, ユーザー名, パスワード)` で接続してログインします。返ったクライアントをアプリ全体で使い回します。

```ts
import { KasaneClient } from "@airbee-project/kasane-client";

const client = await KasaneClient.connect("https://kasane.example.com", "alice", "alice-pass");
```

ログイン状態はクライアントが維持するので、再ログインの処理は要りません。

## 複数のサーバーを指定する

URL を配列で渡すと、サーバーが `[unavailable]` を返したときに次のサーバーへ切り替えます。

```ts
const client = await KasaneClient.connect(
  ["https://kasane-1.example.com", "https://kasane-2.example.com"],
  "alice",
  "alice-pass",
);
```
