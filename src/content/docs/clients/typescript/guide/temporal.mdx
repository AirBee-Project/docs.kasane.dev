時空間ID の定義は[時空間ID の基礎](/concepts/spatial-id/#時空間id)にあります。

`isTemporal: true` で作ったテーブルに、`withTime(時間間隔, 時間インデックス)` を付けた ID で書き込み・検索します。

```ts
await db.createTable("weather", "text", 25, { isTemporal: true });
```

- 時間間隔は 1（`Interval.SECOND`）・60（`MINUTE`）・3600（`HOUR`）・86400（`DAY`）秒のみ
- 時間インデックスは `Math.floor(Date.UTC(2025, 0, 1) / 1000 / 3600)` のように求める
- `RangeId` は `withTime(3600, [開始, 終了])` で時間の範囲を指定できる

実行結果の例：

```text
0 時台: [ '晴れ' ]
0〜1 時台: [ '晴れ', '雨' ]
その日: [ '晴れ', '雨' ]
100 時間後: [ '駅' ]
1800 秒: [invalid_argument] Invalid spatial ID: interval 1800 is not allowed; i must be one of: 34359738368, 86400, 3600, 60, 1
```

- 検索は指定した時間と重なるデータを返す。1 日単位で検索すると、その日の 1 時間単位のデータも返る
- 時間なしの ID で書いた値は全時間の値になり、どの時刻で検索しても返る
- 時間を扱わないテーブルに時空間ID は書き込めない

関連する API：[Interval](/clients/typescript/api/classes/interval/)、[SingleId.withTime](/clients/typescript/api/classes/singleid/#withtime)
