演算と policy の意味は[クエリの考え方](/concepts/query/)にあります。

```ts
import { query } from "@airbee-project/kasane-client";

const q = query
  .source("city", "risk")  // データベース city のテーブル risk
  .filter({ min: 50 })
  .zoomOut(20, "max");

const results = await client.query(q, area, { format: "singleId" }).toArray();
```

- `query.source(データベース名, テーブル名)` から演算をメソッドチェーンでつなぐ。各メソッドは新しい `QueryBuilder` を返す
- `client.query(クエリ, 検索する範囲, オプション)` で実行する。戻り値は `table.search` と同じ `ResultStream`
- オプションの `valueType` は、`mapValues` などで値の型が変わるときに指定する
- `filter` の条件は `{ min, max }`（片方でもよい）・`{ equals: 値 }`・`{ notInRange: { min, max } }`。JSDoc にある `{ inRange: { … } }` は使えない
- `policy` は型の上では省略できるが、省略するとサーバーが `policy must be specified` を返す。`merge` の `defaultValue` も必須

## 試してみる

```text
          x →   X   X+1  X+2  X+3  X+4  X+5  X+6  X+7
risk   Y+1:    80   80   80   80   30   30
       Y  :    80   80   80   80   30   30
wind   Y  :              5    5    5    5    5    5
```

実行結果の例：

```text
filter（50 以上）: 80: 8
intersection: 30: 2、80: 2
difference: 30: 2、80: 6
merge（合計）: 5: 2、30: 2、35: 2、80: 6、85: 2
add（+1）: 31: 4、81: 8
shiftX（10 右へ）: 5: 6
```

| 演算 | 結果 |
| --- | --- |
| `filter({ min: 50 })` | 80 の 8 ボクセル |
| `intersection(wind)` | 両方にある 4 ボクセル（値は risk） |
| `difference(wind)` | risk から wind と重なる 4 ボクセルを除いた 8 ボクセル |
| `merge(wind, { policy: "sum", defaultValue: 0 })` | 重なる部分は合計（85・35）、片方だけの部分はそのまま |
| `add(1)` | 全ボクセルに 1 を足す |
| `shiftX(22, 10)` | 東へ 10 ボクセル移動する |

全演算の書き方は[クエリの一覧](/clients/typescript/reference/query/)にあります。
