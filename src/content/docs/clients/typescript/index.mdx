`@airbee-project/kasane-client` で、TypeScript から Kasane を操作します。Node.js・Bun・ブラウザで動きます。

## インストール

<InstallTabs pkg="https://github.com/AirBee-Project/Kasane-Client-ts/releases/download/v0.0.3/airbee-project-kasane-client-0.0.3.tgz" />

`tsconfig.json` の設定は[動作環境と設定](/clients/typescript/guide/environment/#typescript-の設定)にあります。

## クイックスタート

接続してデータベースを選びます。

```ts
import { KasaneClient } from "@airbee-project/kasane-client";

const client = await KasaneClient.connect("https://サーバーのURL", "ユーザー名", "パスワード");
const db = client.database("データベース名");
```

テーブル `hello` を作り、東京駅付近の空間IDに `42` を書き込んで検索します。

:::note[「実行する」の実行環境]
ブラウザの中で動く Kasane（`KasaneClient.inMemory()`）で動きます。サーバーには接続しないので、書き込んだデータは外に送られません。データはページの中だけにあり、ページを移動したり再読み込みしたりすると消えます。同名のテーブルは作り直されます。
:::
