title: Kasane とは
---

Kasane は、地球上の空間を小さなボクセルに区切り、その 1 つ 1 つに値を保存・検索できるデータベースです。ボクセルの指定には、国のガイドラインで定められた「空間ID」を使います。

たとえば、次のようなデータを扱えます。

- 建物や道路がある場所
- 場所ごとの危険度や人の数
- 1 時間ごとの天気のように、時間とともに変わる値

書き込んだデータは、範囲を指定して検索したり、複数のテーブルを重ね合わせて計算したり（クエリ）できます。

```ts
// 1 時間ごとの雨の強さを入れるテーブルを作る
await db.createTable("rain", "int", 20, { isTemporal: true });
const rain = db.table("rain");

// 東京駅付近の 1 ボクセルに、2025-01-01 0 時台（UTC）の雨の強さ 60 を書き込む
await rain.insert(60, SingleId.parse("20/0/931389/412900").withTime(3600, 482136));

// 周辺の範囲を検索する
const results = await rain.search(RangeId.parse("20/0/931380:931399/412890:412909")).toArray();
```

4. **背景知識**：[時空間IDの基礎](/concepts/spatial-id/)と [Kasane のデータの持ち方](/concepts/data-model/)で、Kasane の考え方を知る
