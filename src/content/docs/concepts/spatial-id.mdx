## 空間ID とは

空間ID は、地球上の空間を格子状に区切ったボクセルのインデックスです。行政の[空間ID ガイドライン](https://www.ipa.go.jp/digital/architecture/Individual-link/rcu1hd000000upgf-att/4dspatio-temporal-id-guideline-v1_2.pdf)で定義されています（このページの図の一部はガイドラインから引用）。

```text
{z}/{f}/{x}/{y}        例：2/0/3/1
```

<div>

| 記号 | 意味 |
| --- | --- |
| `z` | ズームレベル |
| `f` | 高さ方向のインデックス |
| `x` | 東西方向のインデックス |
| `y` | 南北方向のインデックス |

## ズームレベルと親子関係

ズームレベルが 1 上がると、ボクセルは各辺が半分になり 8 分割されます。`f`・`x`・`y` を 2 で割って切り捨てると、1 つ粗いズームレベルの親になります。

```text
3/0/7/2 の親 → 2/0/3/1
20/0/931389/412900 の親 → 19/0/465694/206450
```

インデックスの範囲は、`f` が −2<sup>z</sup> 〜 2<sup>z</sup> − 1、`x`・`y` が 0 〜 2<sup>z</sup> − 1 です。

## 緯度・経度・標高からの変換

`h` は標高（m）です。

```ts
function toSpatialId(z: number, lng: number, lat: number, h: number) {
  const n = 2 ** z;
  const latRad = (lat * Math.PI) / 180;
  const f = Math.floor((n * h) / 2 ** 25);
  const x = Math.floor((n * (lng + 180)) / 360);
  const y = Math.floor((n / 2) * (1 - Math.log(Math.tan(latRad) + 1 / Math.cos(latRad)) / Math.PI));
  return `${z}/${f}/${x}/${y}`;
}

toSpatialId(20, 139.7671, 35.6812, 10); // "20/0/931389/412906"（東京駅）
```

## 空間ID を地図で見る

地図ツール [Senri](https://map.airbee.jp/?debug) で、空間ID の場所を表示できます。

1. 左上の <TablerIcon name="cube" /> 空間ID を押します。
2. <TablerIcon name="plus" /> IDを追加 でできた入力欄に、空間ID を貼り付けます。カンマ区切りで複数指定できます。
3. 入力欄の右の <TablerIcon name="target" /> でその場所へ移動、⬜︎ で色の変更、<TablerIcon name="trash" /> で削除です。

<iframe src="https://map.airbee.jp/?debug" title="空間IDの地図表示" loading="lazy" style="width: 100%; aspect-ratio: 16 / 10; border: 1px solid var(--sl-color-gray-5); border-radius: 4px;"></iframe>

画面右側のボタン：

- <TablerIcon name="refresh" />：範囲で書いた空間ID（[RangeId](/concepts/kasane-spatial-id/#rangeid)）を、範囲として表示するか 1 ボクセルずつ表示するかを切り替える
- <TablerIcon name="border-outer" />：ボクセルの枠線を表示する
- <TablerIcon name="pointer" />：カーソル位置のボクセルの空間ID を表示する
- <TablerIcon name="view-360-number" />：地図を自動で回転させる

<TablerIcon name="plus" /> .txtを追加 で、空間ID を並べたテキストファイル（[Nazori](/tools/plateau/) の出力など）も読み込めます。

## 時空間ID

空間ID に時間インデックスを付けたものです。

```text
{z}/{f}/{x}/{y}_{i}/{t}    例：20/0/931389/412900_3600/489768
```

![左に 3 次元の空間ID、右に同じ空間ID を時間ごとに区切った 4 次元の時空間ID を並べた図](../../../assets/ipa/ipa-fig2-21-spatial-vs-temporal.png)

<p class="figure-caption">図 2-21 空間 ID と時空間 ID の比較イメージ（出典：[空間 ID ガイドライン 1.2 版](https://www.ipa.go.jp/digital/architecture/Individual-link/rcu1hd000000upgf-att/4dspatio-temporal-id-guideline-v1_2.pdf)）</p>

時間軸を UNIX エポックから時間間隔 `i`（秒）ごとに区切り、UNIX 時間 `u` が入る区間の番号を `t = floor(u / i)` とします。

![時間軸の起点から時間間隔 i ごとに区切り、UNIX 時間 u が入る区間の番号を時間インデックス t とする図](../../../assets/ipa/ipa-fig2-23-time-elements.png)

<p class="figure-caption">図 2-23 分割された時間軸における各要素（出典：[空間 ID ガイドライン 1.2 版](https://www.ipa.go.jp/digital/architecture/Individual-link/rcu1hd000000upgf-att/4dspatio-temporal-id-guideline-v1_2.pdf)）</p>

```ts
const t = Math.floor(Date.UTC(2025, 10, 15, 0, 0, 0) / 1000 / 3600); // 489768
// 20/0/931389/412900_3600/489768 は、2025-11-15 00:00〜01:00（UTC）
```

時間インデックスを付けない空間ID は、全時間を表します。
