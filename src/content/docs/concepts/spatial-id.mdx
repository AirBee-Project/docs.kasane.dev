## 空間ID とは

空間ID は、地球上の空間を格子状に区切ったボクセルのインデックスです。IPAの[空間ID ガイドライン](https://www.ipa.go.jp/digital/architecture/Individual-link/rcu1hd000000upgf-att/4dspatio-temporal-id-guideline-v1_2.pdf)で定義されています。書式は `z/f/x/y` で、例えば `2/0/3/1` のように書きます。

| `f` | 高さ方向のインデックス |
| `x` | 東西方向のインデックス |
| `y` | 南北方向のインデックス |

## ズームレベルと親子関係

ズームレベルが 1 上がると、ボクセルは各辺が半分になり 8 分割されます。`f`・`x`・`y` を 2 で割って切り捨てると、1 つ粗いズームレベルの親になります。例えば、`3/0/7/2` の親は `2/0/3/1` となり、`20/0/931389/412900` の親は `19/0/465694/206450` です。

インデックスの範囲は、`f` が −2<sup>z</sup> 〜 2<sup>z</sup> − 1、`x`・`y` が 0 〜 2<sup>z</sup> − 1 です。


## 時空間IDとは

時空間ID は、空間ID に時間インデックスを付けたものです。同じ空間ID でも、時間インデックスが違えば別の時空間ID になります。

![左に 3 次元の空間ID、右に同じ空間ID を時間ごとに区切った 4 次元の時空間ID を並べた図](../../../assets/ipa/ipa-fig2-21-spatial-vs-temporal.png)
<p class="figure-caption">図 2-21 空間 ID と時空間 ID の比較イメージ（出典：[空間 ID ガイドライン 1.2 版](https://www.ipa.go.jp/digital/architecture/Individual-link/rcu1hd000000upgf-att/4dspatio-temporal-id-guideline-v1_2.pdf)）</p>

時間軸を UNIX エポックから時間間隔 `i`（秒）ごとに区切り、UNIX 時間 `u` が入る区間の番号を `t = floor(u / i)` とします。書式は `{z}/{f}/{x}/{y}_{i}/{t}` で、例えば `16/0/58210/25800_1/0` のように書きます。

![時間軸の起点から時間間隔 i ごとに区切り、UNIX 時間 u が入る区間の番号を時間インデックス t とする図](../../../assets/ipa/ipa-fig2-23-time-elements.png)

<p class="figure-caption">図 2-23 分割された時間軸における各要素（出典：[空間 ID ガイドライン 1.2 版](https://www.ipa.go.jp/digital/architecture/Individual-link/rcu1hd000000upgf-att/4dspatio-temporal-id-guideline-v1_2.pdf)）</p>

```ts
const t = Math.floor(Date.UTC(1970, 0, 1, 0, 0, 0) / 1000 / 1); // 0
// 16/0/58210/25800_1/0 は、1970-01-01 00:00:00〜00:00:01（UTC）
```

## 時空間ID を地図で見る

地図ツール [Madori](https://madori.airbee.jp/) で、時空間ID の場所を表示できます。

1. 左上の <TablerIcon name="cube" /> 空間ID を押します。
2. <TablerIcon name="plus" /> IDを追加 でできた入力欄に、`19/0/465694/206453_3600/489768` のような時空間ID を貼り付けます。
3. 入力欄の右の <TablerIcon name="focus-centered" /> でその場所へ移動し、⬜︎ で色を変え、<TablerIcon name="trash" /> で削除します。
4. 時空間IDの場合、下にあるタイムバーの時刻を含むものだけが表示されます。

[Madori の使い方](/tools/madori/)で、詳しい使い方を確認できます。
