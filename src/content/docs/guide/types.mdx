## 値の型

テーブルの値の型は、作るときに決めます（[データベースとテーブル](/guide/databases/)）。書くときと読むときの JavaScript の値は次のとおりです。

| 型 | 書く値 | 読んだ値 |
| --- | --- | --- |
| `"text"` | `string` | `string` |
| `"int"` | `number` または `bigint` | `bigint`（`80n` など） |
| `"boolean"` | `boolean` | `boolean` |
| `"enum"` | 選択肢の `string` | `string` |
| `"presence"` | `null` | `null` |

- INT の値は `bigint` で返ります。普通の数値にしたいときは `Number(value)` で変換します。
- 小数の型はありません。INT に `3.9` を渡すと、クライアントで `3` に切り捨てられます。小数を扱うときは、10 倍や 100 倍した整数にします。
- PRESENCE は「そこに何かがある」ことだけを記録する型です。値は `null` です。

## 制約

`createTable` の `constraints` で、書き込める値を制限できます。制約に違反する値や、型に合わない値を書くと、`[invalid_argument]` のエラーになります。

| 型 | 書き方 |
| --- | --- |
| INT | `{ kind: { case: "int", value: { min: 0n, max: 100n } } }` |
| TEXT | `{ kind: { case: "text", value: { minLength: 1n, maxLength: 20n } } }` |
| ENUM | `{ kind: { case: "enumConstraint", value: { choices: ["晴れ", "曇り", "雨"] } } }` |

数値は `bigint` で書きます。v0.0.3 では、制約の型がサーバーの API の型そのままなので、`as never` を付けないと型エラーになります。

## TypeScript での値の型

`db.table<T>(名前)` の型引数 `T` は、書く値と読む値の両方に使われます。INT のテーブルでは書く値（`number`）と読む値（`bigint`）が違うので、v0.0.3 では型引数を付けずに使うのがおすすめです。

```ts
const table = db.table("risk");       // 値の型は PrimitiveValue
await table.insert(80, id);
const results = await table.search(id).toArray();
const value = results[0]?.value;       // string | number | bigint | boolean | null | undefined
```

読んだ値は `typeof value === "bigint"` などで型を確かめてから使います。

## まとめ

- 型は text・int・boolean・enum・presence の 5 つ。INT は `bigint` で返る
- 制約を付けると、範囲外の値や選択肢に無い値を防げる
